# ADR-0009: Administrators can record results (staffing flexibility)

- **Status:** Superseded by [ADR-0016](0016-role-model-simplification.md)

## Context

Under the original six-role model, creating entries needed an event administrator and submitting results needed an assigned results official, so no single-role user could complete the result screen, and an administrator was refused when recording a result. Schools routinely have administrators step in as recorders.

## Decision

Event administrators could submit and correct results for any event, without the per-event assignment check that bound results officials. Verification and finalisation stayed with the verifier.

[ADR-0016](0016-role-model-simplification.md) replaced the role model: four roles, with result capture and correction held by Recorder, Carnival Administrator and System Administrator, and per-event assignment advisory only.
