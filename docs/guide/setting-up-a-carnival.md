# Setting up a carnival

How to get a new carnival ready, from creating it to opening it on the day. You need to be a carnival administrator or a system administrator. Only a system administrator can import the student list.

Every carnival is set up in the same four steps: **Students**, **Events**, **Program** (optional) and **Open**. You can stop at any point and come back later.

## Create the carnival

1. Go to **Carnivals** and press **New carnival**.
2. Fill in the name, type (the sport), date and venue, and the number of lanes.
3. Press **Create**. The app takes you to the carnival's **Manage** page.

Manage has a list headed **Set the carnival up**. It shows the four steps, ticks off each one when it is done, and marks the next one **Do this next**. Each step has a button that takes you to the right screen.

## 1. Students

The carnival's ages come from the student list, so it goes in first.

1. On Manage, press **Import the students**. The year is filled in from the carnival's date.
2. Choose the CSV export from your student system. The app checks it and shows what will change. If some rows can't be imported, a line above the table says how many and why, for example "2 have no house". The rest can still go in; fix those students in your student system and import again later.
3. Read the table, then press **Approve and update the student list**. The app says what changed, for example "Student list updated: 96 students added".
4. Press **Back to** *your carnival* to return to Manage.

There is one student list for the whole school. If another carnival this year already imported it, this step is already done.

If you are not a system administrator, the step says so: ask one to import the list.

The import checks each student's house against the school's houses, so the school needs them first. If none are set up yet, the upload is refused and the screen offers **Add the houses in School settings**: add them there, press **Save**, and upload the file again.

## 2. Events

Press **Add events** on Manage to open **Event setup**.

Near the top, one line shows the ages, categories and tiers this carnival will use, for example "Ages 12–18 from the student list · Boys, Girls · Competitive".

- **Ages** come from the student list. You can leave some out, but you can't add an age no student has.
- **Categories** are Boys, Girls and Open (boys and girls together).
- **Tiers** are Competitive and Social.

To change them, press **Ages and categories**, make your changes and press **Save**.

Then add the events:

- **The quick way:** on a new carnival, press **Add the standard swimming events** (or athletics). One press adds the usual events with a division for every age, category and tier, and builds a program. Pressing it again adds only what is missing.
- **One at a time:** under **Available to add**, press **Add** beside an event.
- **Something new:** press **New event…** to create an event the list doesn't have.

Once the carnival has events, the standard events sit behind **Add the rest of the standard events**.

To run an event for fewer ages, open it from **In this carnival** and untick the boxes you don't want.

If Event setup says **Import the student list first**, step 1 isn't done yet.

### When the student list changes

Importing a new student list never changes a carnival's saved ages by itself.

- If the carnival has an age no student has any more, Event setup warns you. Press **Remove those ages** to fix it.
- If the student list has ages the carnival leaves out, Event setup notes them quietly. That is fine if you left them out on purpose. Otherwise, add them on **Ages and categories**.

## 3. Program (optional)

The program is the timed running order that staff print. A carnival runs without one.

Press **Build the program** on Manage. If you added the standard events, a program is already built: check it and change it as you need. Press **Printable program** to see the copy you print.

## 4. Open

You open the carnival from the last step of the checklist on Manage. Under **4. Open**, Manage counts the events and divisions and lists anything worth checking under **Before you open**, such as:

- a student list from a different year;
- divisions for an age no student has;
- divisions that aren't in the program, such as ages the program doesn't cover, with an **Add them to the program** link.

These are warnings only. You can still open. The buttons are in the same step:

- **Open carnival** opens the carnival and every event in it, ready for results. Most schools want this.
- **Open the carnival only** leaves each event waiting until you open it on the Deck, for schools that open events as they are called.

Results can only be recorded while both the carnival and the event are open. On the day, you can open and close single events from the Deck.
